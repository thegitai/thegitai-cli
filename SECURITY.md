# Security

TheGitAI is a proprietary client/server product. This repository contains only
the source-visible local client snapshot.

Do not report security issues by opening public issues that include secrets,
private code, exploit details, or customer data. Email security@thegit.ai with a
concise description and reproduction details that do not expose third-party
confidential information.

The local client is untrusted for enforcement. Authentication, authorization,
entitlements, quota, provider access, model routing, prompts, orchestration, and
telemetry policy are server-owned.
